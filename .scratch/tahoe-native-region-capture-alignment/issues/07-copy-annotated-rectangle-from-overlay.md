# Copy Annotated Rectangle From Overlay

Status: done
Type: AFK

## Parent

[Tahoe Native Region Capture Alignment](../../../tech-designs/tahoe-native-region-capture-alignment.md)

## What to build

Introduce the minimum annotation-mode vertical slice on the same overlay surface: after selecting a region, show a compact toolbar, let the user draw a rectangle annotation over the captured region, undo it, then copy a flattened annotated PNG.

This is the architectural hinge for the annotation workflow. Keep the slice narrow: prove that the owned overlay can transition from region selection into in-place annotation and can export a flattened PNG without opening the old editor window.

## Acceptance criteria

- [x] Mouse-up after region selection enters annotation mode on the same overlay surface.
- [x] A compact toolbar appears only after a region exists.
- [x] Rectangle tool creates vector annotations in image-space coordinates.
- [x] Annotation identity is stable after creation.
- [x] `Cmd+Z` or the toolbar Undo removes the last created rectangle annotation.
- [x] Copy flattens the base screenshot and rectangle annotations into PNG data and closes on success.
- [x] The old separate editor window is not used for this flow.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Add the first in-overlay annotation slice: draw rectangle annotations over the selected capture and copy a flattened PNG.

**Current behavior:**
The owned overlay supports region selection, native region capture, raw PNG copy, and raw PNG save. After a region is captured, the overlay shows post-selection actions, but it does not yet enter a real annotation mode. The older separate editor window and existing annotation scaffold are not the target flow for this MVP path.

**Desired behavior:**
After the user completes a region selection and the selected region image is captured, the same overlay should become an annotation surface for that selected region. A compact post-selection toolbar should expose at least Rectangle, Undo, Copy, and Close/Escape behavior. The user should be able to draw one or more rectangle annotations over the selected image area, undo the most recent rectangle, then copy a PNG containing the base captured image flattened with the rectangle annotations. Successful copy closes the overlay.

Rectangle annotations should be stored in captured-image coordinate space, not transient overlay/window coordinates. Convert pointer input from the overlay selection area into image-space coordinates using the captured image dimensions and the selected region's displayed bounds. This must continue to behave correctly on Retina displays, where display points and captured image pixels may differ.

Annotation identity must be stable after creation. Do not use a computed identifier that returns a new UUID on each access.

**Key interfaces:**
- The overlay session state should distinguish selection, captured/annotation-ready, and annotation-dragging behavior so a post-selection drag creates a rectangle instead of starting a new region selection.
- The annotation model should represent rectangle annotations with stable identity and image-space geometry.
- The PNG export boundary should flatten the captured base image plus rectangle annotations into PNG data before handing it to the clipboard service.
- Keyboard handling should route `Cmd+Z` to undo when annotation mode is active and keep `Esc` as cancel/close.

**Acceptance criteria:**
- [ ] Completing a valid region selection captures the base image and leaves the user on the same overlay surface in annotation mode.
- [ ] The toolbar is hidden before a valid region exists and visible after the base image is ready.
- [ ] Dragging inside the selected image area while Rectangle is active creates a rectangle annotation.
- [ ] Stored rectangle geometry is in captured-image coordinates and exports at the correct visual position/size in the copied PNG.
- [ ] Each created annotation has stable identity for its lifetime.
- [ ] `Cmd+Z` removes the most recently created rectangle annotation.
- [ ] Toolbar Undo removes the most recently created rectangle annotation.
- [ ] Copy writes a flattened PNG containing the base image and all remaining rectangle annotations to `NSPasteboard`.
- [ ] Successful annotated copy closes all overlay UI.
- [ ] This flow does not open or depend on the old separate screenshot editor window.
- [ ] `swift build` succeeds.

**Out of scope:**
- Arrow annotations.
- Text annotations.
- Freehand draw annotations.
- Highlight/color/stroke controls beyond a simple hardcoded rectangle style.
- Saving annotated PNGs.
- Reworking the preferences UI.
- Removing the old editor code entirely, unless it is necessary to prevent this flow from using it.
