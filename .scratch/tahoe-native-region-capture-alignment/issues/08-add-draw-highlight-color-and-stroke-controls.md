# Add Draw Highlight Color And Stroke Controls

Status: done
Type: AFK

## Parent

[Tahoe Native Region Capture Alignment](../../../tech-designs/tahoe-native-region-capture-alignment.md)

## What to build

Expand annotation mode with the fast markup controls needed after the rectangle tracer bullet: freehand draw, highlight, color, and stroke size. Copy should continue to flatten all visible annotations into the final PNG.

## Acceptance criteria

- [x] Draw/freehand annotations can be created over the selected image.
- [x] Highlight annotations render with visible translucent emphasis and no dedicated blur/redaction behavior.
- [x] Toolbar color selection affects newly created draw, rectangle, and highlight annotations where appropriate.
- [x] Toolbar stroke size selection affects newly created draw, rectangle, and highlight annotations where appropriate.
- [x] Toolbar color control uses an anchored in-overlay picker instead of cycling through a fixed color list.
- [x] Toolbar stroke size control uses a better picker UX than cycling, preferably a vertical range picker with clear stop points.
- [x] Undo removes the most recent annotation across rectangle, draw, and highlight tools.
- [x] Copied PNG output matches the on-overlay annotation preview closely enough for daily use.
